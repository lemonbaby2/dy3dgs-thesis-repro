# 重复验证报告（Repeatability & Stability）

> 目的：回答一个问题——**这些数字能不能信？**
>
> 硕士阶段的实验结论，单次运行不足以支撑。本目录记录两类重复验证：
> ① 官方 3DGS 在同一数据上连续三次训练的波动量级（**测量误差**）；
> ② 自建合成动态场景 3 配置 × 3 随机种子的结论稳定性（**结论是否依赖运气**）。

- 日期：2026-11-11
- 硬件：NVIDIA GeForce RTX 4060（sm 8.9，8188 MiB），`CUDA_VISIBLE_DEVICES=0`
- 软件：torch 2.1.2 + CUDA 11.8，官方 3DGS 固定提交

---

## 零、结论先行

| 判据 | 数值 | 含义 |
|---|---|---|
| 官方 3DGS 三次 PSNR 标准差 | **0.019 dB** | 这是代码在本机的固有波动上限 |
| 官方 3DGS 三次 PSNR 极差 | 0.035 dB | 三次中最差与最好只差这么点 |
| 合成场景 seed0 静态区提升 | **+3.57 dB** | 是固有波动的 **191 倍** |
| 合成场景 seed0 残影下降 | 0.0816 → 0.0048（**1/17**） | 量级变化，非噪声 |
| 三配置静态区排序 | 三个种子全部一致 | 结论不依赖随机种子 |

**铁律**：本机上，**小于 0.02 dB 的 PSNR 差异不得解释为方法改进**。任何声称"提升 0.01 dB"的说法在这套硬件上无法与噪声区分。

## 一、官方 3DGS：三次 7000 迭代重复训练

### 1.1 协议

同一数据集（`nerf_synthetic/lego_white_rgb`，白底 RGB 预处理）、同一超参（7000 次迭代、`--eval`、100 留出视角）、连续三次**独立**训练，每次训练完各自 `render.py --skip_train` + `metrics.py` 评测。

与主结果 30000 次的区别只有迭代数，其余一致。

### 1.2 逐次结果

| 运行 | PSNR (dB) | SSIM | LPIPS |
|---|---|---|---|
| `verify7k_r1` | 34.8659 | 0.97970 | 0.02222 |
| `verify7k_r2` | 34.8311 | 0.97945 | 0.02257 |
| `verify7k_r3` | 34.8366 | 0.97946 | 0.02249 |

### 1.3 统计

| 指标 | 均值 | 标准差 | 极差 |
|---|---|---|---|
| PSNR | **34.8445 dB** | **0.0187 dB** | 0.0347 dB |
| SSIM | 0.979539 | 0.000142 | 0.000249 |
| LPIPS | 0.022427 | 0.000181 | 0.000345 |

### 1.4 判定

- 三次 PSNR 全部落在 `34.83–34.87` 区间，标准差 **0.019 dB**，相对均值波动 **0.054%**。
- SSIM 波动在万分之一个量级（0.9794–0.9797），LPIPS 波动在万分之三个量级。
- **这个波动不是 bug**。来源是 GPU 非确定性（光栅化原子累加顺序、`simple_knn` 距离排序、cuDNN benchmark）与数据加载顺序，即使固定全部随机种子也无法完全消除。

> 该 7000 迭代结果（34.84 dB）低于 30000 迭代主结果（37.41 dB），是**迭代数不同**导致的正常差异，不是矛盾。两者不可横向比较。

原始数据：`official_repeat_3x.json`。

## 二、合成动态场景：3 配置 × 3 随机种子

### 2.1 三配置语义

| 配置 | 说明 | 验证什么 |
|---|---|---|
| `naive` | 不做任何动态处理，直接对全部像素求光度损失 | 基线（有残影） |
| `no-dyn-data` | 仅用动态掩码做**初始化滤波**（剔除动态区点） | 只处理输入够不够 |
| `dyn-mask` | 掩码加权损失：动态区权重置零，只监督静态区 | 完整方案 |

### 2.2 seed0 结果（已完成）

| 配置 | 全图 PSNR | **静态区 PSNR** | SSIM | **残影残差** |
|---|---|---|---|---|
| `naive` | 22.585 | 30.777 | 0.9069 | 0.0816 |
| `no-dyn-data` | 22.271 | 31.444 | 0.9077 | 0.0642 |
| `dyn-mask` | 21.103 | **34.351** | 0.9185 | **0.0048** |

**关键读法**：

1. `dyn-mask` 的**全图** PSNR（21.10）反而**最低**——因为它主动放弃了对动态区域的拟合。这是设计意图，不是缺陷。若只看全图 PSNR，会得出完全相反的结论。
2. 真正该看的是**静态区 PSNR**：`dyn-mask` 34.351 vs `naive` 30.777，**+3.574 dB**。
3. 残影 0.0816 → 0.0048，降至 **1/17**，靠初始化滤波（`no-dyn-data`，0.0642）只能降到原来的 79%，**远不够**。

## 三、如何自己重跑

```bash
# 官方三次重复
cd D:/GS_Repro/src/official/gaussian-splatting
for i in 1 2 3; do
  CUDA_VISIBLE_DEVICES=0 python train.py -s <lego_white_rgb> -m <out_r$i> \
    --eval --iterations 7000 --test_iterations 7000 --save_iterations 7000 -w
  CUDA_VISIBLE_DEVICES=0 python render.py -m <out_r$i> --skip_train
  CUDA_VISIBLE_DEVICES=0 python metrics.py -m <out_r$i>
done

# 合成场景 9 次
cd synthetic/code && python run_multiseed.py
```

预计耗时：官方三次约 10 分钟（3 分 16 秒 / 次 + 评测），合成 9 次约 66 分钟（单次 441 秒）。
